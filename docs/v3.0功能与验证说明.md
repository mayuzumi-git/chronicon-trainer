# v3.0 功能与验证说明

## 功能

- 主窗口改为左侧功能列表、右侧独立编辑页；寻宝值、拾取范围、掉落品质、击杀材料掉落、独特敌人追踪和地图点亮各自应用。切换页面不更改状态；物品添加器、附魔修改器保持独立窗口。所有持续覆盖开关默认关闭。
- 物品目录新增装备之下的法器子分类。最终目录包含 697 件装备，其中 23 件法器；按用户要求从目录移除法典 [731]，引擎同时拦截该编号的通用生成。
- 删除货币／代币大类，保留独立的水晶 [0] 分类；其他资源继续通过材料掉落物获得。
- 空白符文石与 120 种掉落次级符文合并为符文大类，点击大类可搜索全部 121 项，也可选择子分类。

## 击杀掉落实现

原生材料具有怪物与场景来源条件，没有统一的任意怪物掉率。经用户确认，扩展功能统一采用原生特殊怪材料的 `irandom(2) == 0` 判定；原生随机函数返回 0、1 或 2，因此每种成功概率约 1/3。每次击杀分别判定编号 847–858，各种材料独立。

在 `actorDeathDrops` 的公共尾部安装补丁，原生战利品逻辑先照常执行。只处理已确认的 enemy 派生对象，排除木人与玩家。每种判定成功后，通过已验证的原生物品生成及 quantity 写入流程创建一份材料堆，再由 `itemDropSpecific` 以死亡怪物为上下文生成在其位置。

数量倍率是 1–1,000 的整数；一次判定成功只创建一堆，堆叠数量为倍率。通过死亡事件触发，不定时扫描场景。远程数据只保存开关、倍率、重入保护及统计；状态面板仅读取小块数据。

补丁保存寄存器、标志和易失浮点寄存器，执行完成后回到原生清理流程。安装前检查游戏哈希与原始指令，卸载前检查补丁归属，卸载后恢复原指令。关闭开关停止后续扩展掉落，已经产生的物品照常保留。

相关文件：`MainWindow.cs`、`KillMaterialEngine.cs`、`KillMaterialProfile.cs`、`InventoryWindow.cs`、`InventoryEngine.cs`、`ItemCatalog.cs`。C# 编译入口仍为 `build.ps1`。

## 2026-10-18 验证

- 原生代码测试通过：12 次独立原生随机调用、全部／部分／全部不掉落、数量倍率 1／3／1,000、材料编号范围、怪物上下文、关闭覆盖、木人与玩家排除，以及重入状态释放。
- 界面测试通过：6 个独立功能页、每次只显示所选页、控件边界、默认关闭、倍率范围；23 件法器位于装备子分类、法典从目录移除、697 件装备、121 项合并符文、只保留水晶的入口。已渲染并目视检查主窗口与物品窗口。
- 针叶林实测：生成「芬利的魔法地图」[699] 1 件；开启 3 倍材料掉落后记录 14 次击杀、54 堆扩展材料，用户确认法器与材料正常。
- 测试结束关闭材料开关，并回读确认死亡掉落补丁、物品请求补丁均恢复为原指令。

初期法典样品使用通用生成时导致游戏退出；根据用户补充和最终要求，已移除该样品及生成目录条目，并保留引擎拦截。运行日志保留初期失败与最终成功记录。最终版不再提供法典生成。

法器其余条目未逐件生成；材料数量上限通过机器代码验证，游戏内数量验证为 3 倍。地图与附魔等既有功能本轮没有重复进行游戏操作测试。
