# 拾取范围（v2.9）

主窗口的「指定拾取范围（%）」位于寻宝值之后。勾选、输入百分比并点击「应用设置」，切回游戏即可执行。范围为 0–1,000,000%，支持两位小数，默认不启用。

数值采用角色面板的百分比口径。游戏内部的属性编号为 36，110% 对应内部值 1.1。原生拾取半径计算为 `72 × (1 + 属性值)`，所以 0% 保留基础距离，500% 对应 432 个世界坐标单位；物品是否允许自动拾取仍遵循游戏自身规则。

## 实现

- 首次应用通过游戏主线程调用原生 `statGet(0, 36)` / `statSet(0, 36, value)`，立即读取并设置本机角色属性。
- 在原生 `playerStatSetCaps` 属性刷新结束处安装补丁。换装等操作重新计算属性后，捕获自然值并重新应用所选范围；无需定期遍历物品或地图。
- UI 状态刷新只读取小块缓存；执行原生请求时界面保持响应，并提示切回游戏。
- 取消勾选并应用、恢复原始状态或正常退出时，还原捕获的自然值。卸载时核对补丁归属，并恢复原指令。修改期间换过装备时，可再切换一次装备重新计算自然属性。
- 绑定已分析的游戏 EXE 哈希和原始指令，适用范围与综合修改器一致。

相关源码：`PickupEngine.cs`、`PickupProfile.cs`、`Trainer.cs`。`build.ps1` 已加入新文件，使用 Windows 自带的 .NET Framework C# 编译器即可构建。

## 验证记录

2026-10-18，本机运行验证：

- 自然拾取范围为 110%；设置为 500%，用户确认生效。
- 测试期间触发 51 次属性刷新，原生属性查询仍为 500%。
- 依次设置 1,000%、0%，原生查询与目标一致。
- 关闭覆盖后恢复为 110%；重新启用后卸载，仍恢复为 110%。
- 拾取范围补丁与请求执行补丁均回读确认已恢复原指令。

原生机器代码测试另覆盖零值、小数、上限、脚本参数、重复刷新时的自然值保护、换装后捕获新自然值及关闭覆盖。界面检查覆盖默认关闭、输入范围与精度、控件顺序和完整窗口布局。

验证文件位于交付包的「验证记录」目录：`pickup_live.log`、`PickupNativeTests.cs`、`ValidatePickupUI.cs`、`pickup_ui.png`。未逐项测量每类掉落物的实际拾取距离。
