# v3.0.1：诅咒与赐福装备附魔读取修复

修复将诅咒或赐福装备放入附魔师后，修改器提示「不支持的装备字段类型：10」的问题。

游戏可将 `curse_id`、`bless_id` 保存为 64 位整数，而旧解析器只支持双精度、布尔和字符串。现在支持原生类型 7（32 位整数）与 10（64 位整数），字段字典保留整数原值，现有数值读取逻辑可正常访问。原始序列化数据不重新编码，读取与候选池查询不修改装备。

本次仅修改 `EnchantItem.cs` 的字段解析与数值访问，其他运行时附魔补丁与预选规则保持原实现。
