# Chronicon 综合修改器 v3.0

双击同目录的 **Chronicon修改器.exe**。无需安装 Python，使用 Windows 自带的 .NET Framework。

1. 启动 Chronicon，进入角色，点击「连接游戏」。
2. 从左侧选择功能，右侧显示该功能独立的开关、数值或操作按钮。
3. 设置右侧开关与数值，点击 **「应用此功能」**；自动点亮使用「应用自动点亮开关」。切换页面本身不会开关功能，也不会应用其他页面的待修改数值。
4. 原生查询需要游戏主线程执行，处理时请切回游戏；暂停时请求会等待。寻宝值应用后切换一次装备刷新属性。
5. 底部 **「物品添加器」** 与 **「附魔修改器」** 保留独立窗口。

左侧功能：

- **寻宝值**：0–1,000,000%，两位小数；关闭并应用恢复自然值。
- **拾取范围**：0–1,000,000%，两位小数，换装刷新后继续保持。0% 保留基础拾取距离；关闭并应用恢复自然值。
- **装备掉落品质**：开启后指定普通、附魔、稀有、独特、传奇或真传奇；关闭后沿用原概率。仅覆盖随机装备生成，不转换已有物品。固定品质奖励、任务和配方沿用游戏规则；真传奇仍受等级、物品池与掉落来源约束。
- **击杀掉落 12 种材料**：详见下方；默认关闭。
- **独特敌人追踪**：独立开启敌人与互动触发点标记，右侧列出目标状态与坐标。
- **地图点亮**：独立设置进图自动点亮，或手动点亮当前地图一次。

主窗口点击 **「恢复全部功能」** 或正常关闭程序，会恢复运行时补丁及捕获的自然寻宝值、拾取范围，关闭追踪、自动点亮与材料扩展掉落。修改期间换过装备或难度时，恢复后再切换一次装备，重新计算自然属性。程序意外退出时，重启游戏即可清除运行时补丁。已拾取物品、增加的资源及已探索地图仍按游戏自身机制保留。

## 任意怪物扩展材料掉落

开启后，每只进入原生死亡掉落流程的敌人，都会对 **树人外皮 [847] 至富集灰烬 [858]** 的 12 种材料分别进行一次判定。

经本次确认，统一沿用原生特殊怪材料的 `irandom(2) == 0` 判定，每种概率约 **1/3**，彼此独立；所以一次击杀可能掉落多种材料，也可能不掉落。这里不再保留原生的特定怪物或场景来源限制。

**数量倍率可设 1–1,000 倍，只影响判定成功后的堆叠数量。** 例如 3 倍时，每种成功判定的材料生成一堆 3 个，在怪物死亡位置拾取。原本的战利品流程继续执行。关闭并应用后停止扩展掉落；已经生成或拾取的材料保留。

仅在死亡事件发生时处理，不轮询地图。每次最多 12 次原生随机判定，成功项每种生成一堆；木人与玩家不参与。高倍率增加堆叠数量，不按倍率逐个创建掉落实例。

已在针叶林实测：生成 1 件「芬利的魔法地图」并由用户确认正常；3 倍模式记录到 14 次击杀、54 堆材料，用户确认材料与法器正常拾取。测试开关已关闭，死亡事件和物品请求补丁均回读确认恢复。

修改器不编辑安装文件或直接编辑存档。通过游戏正常拾取、保存的装备会照常保留。仅适用于本机单人游戏；不要在多人会话中使用。

如果出现「游戏版本不匹配」，不要跳过检查。本工具绑定本次分析的 EXE；Steam 更新游戏后需重新分析和适配。出现访问被拒绝时，让游戏与修改器使用相同的运行权限，必要时以管理员身份运行修改器。

## 添加装备、宝石、符文石与资源

主窗口点击 **「物品添加器」**，在左侧分类树选择种类，输入名称或编号搜索，选中目标并填写数量。

- **装备**：697 个经当前游戏目录确认的条目，包含装备子分类「法器」中的 23 种可生成法器，按名称生成，单次 1–1,000 件；等级可设 1–100。装备生成在角色脚边，按物品自身品质生成完整属性，每件独立随机词条，请正常拾取。此功能不批量复制背包已有装备。
- **法器子分类**：23 种，位于装备之下，支持「芬利的魔法地图」等可掉落法器，以及注射器、发射器。按用户要求移除需要配方绑定技能的法典 [731]，避免通用生成缺少技能数据导致游戏报错。
- **材料**：44 种材料／代币，填写要生成的总数量，单次 1–1,000,000,000。点击「生成材料掉落物」后，在角色脚边生成可拾取的材料堆叠，正常拾取后才获得。普通制作材料进入背包；魔法精华等抽象资源按游戏规则入账，可能自动吸取。
- **水晶 [0]**：独立分类，填写要增加的数量，可读取余额。已移除「货币／代币」大类；其他精华、代币仍可通过材料分类生成掉落物。
- **宝石**：63 种，包含 7 种宝石的方形／球形／星形、粗糙／切削／磨光组合。按完整名称或编号搜索，单次增加 1–1,000,000,000 个，直接进入宝石页；例如搜索「磨光星形紫龙晶」。
- **空白符文石**：列表名称为「空白符文石（符文石）」，编号 741；游戏内中文名称为「符文石」。单次生成 1–1,000 个，出现在角色脚边，需正常拾取。
- **掉落次级符文**：120 种异境掉落符文，通用、圣骑士、狂战士、守望者、术士、机械师各 20 种。展开「符文」，选择「掉落次级符文」，按名称、职业或编号搜索，单次生成 1–1,000 个，在角色脚边拾取；例如搜索「至高无上」「格挡大师」或「机械师」。列表限定为当前版本的掉落池，不包含从装备提取的手工符文；空白符文石与掉落次级符文已合并在「符文」大类，点击大类可搜索全部 121 个条目。能力、等级、职业及适用装备限制沿用游戏原生生成结果。

点击生成／添加后，**切回游戏并保持角色在场景中**。游戏暂停时请求会等待，点击「取消剩余操作」可以停止尚未执行的部分；已经生成的物品和已经入账的资源会保留。背包材料界面未更新时，请关闭并重新打开背包。

「读取当前数量」对普通材料读取角色实际物品数量，对精华类资源、货币和宝石读取对应余额。材料掉落后需要拾取，生成时不按余额增量判断成功；货币和宝石继续在添加前后自动回读增量，同期拾取同种资源可能影响核对结果。

**「恢复原始状态」只恢复运行时补丁，不会删除新增物品或扣回资源。** 物品和资源会随游戏正常保存。不要重复点击添加来判断暂停中的请求是否生效，请先切回游戏或取消等待请求。

已实测：添加 2 件皮革兜帽（用户确认两件均出现且可正常拾取）、7 魔法精华、100 水晶；材料和水晶增量回读一致，临时补丁恢复已核对。其他条目通过了游戏目录读取，未逐一生成测试。

v2.7 修复材料直接入账对普通制作材料无效的问题：已生成并由用户确认拾取「符文领主之悔意」3 个与「魔法精华」3 个。拾取后实际物品查询为 3 个，精华余额由 99,923,741 增至 99,923,744；临时补丁恢复通过回读核对。44 种材料未逐项实测。宝石、货币、装备、符文石及地图功能保持原有操作方式。

v2.8 新增掉落次级符文：已从本机游戏读取 120 种掉落符文及手工符文池，确认列表与掉落池完全一致且无手工池条目；120 种原生生成数据的基础物品、能力、职业和异境符文名称均逐项通过核对。已在同一位置生成「至高无上」2 个、「格挡大师」1 个、「弹药回复」1 个，用户确认正常拾取；其余符文未逐项进行拾取或镶嵌测试。

测试新增物品和资源按用户确认保留。

v2.1 已实测：粗糙方形、切削球形、磨光星形紫龙晶各增加 3 个，三项回读增量一致；生成 2 个符文石，用户确认已拾取。临时补丁恢复已核对。

## 预选整套附魔，一次洗出

1. 在游戏的附魔师界面放入要修改的装备。**解除需要修改的普通词条锁定，无需锁定其他词条**；固定能力保持原样。
2. 修改器连接游戏后，点击主窗口的 **「附魔修改器」**。
3. 点击 **「读取附魔师装备」**，随后切回游戏让查询执行。
4. 未锁定槽位会默认预选原词条。逐个选择槽位，搜索目标词条，再点击 **「设为此槽位目标」**。上方每行的箭头右侧就是该槽位已保存的目标。
5. 完成整套选择后，点击 **「准备整套洗牌」**，切回游戏，在附魔师点击一次 **「洗牌」**，同时应用全部预选。**「重掷」只改变数值，不会触发词条类别选择。**
6. 查看游戏结果。整套预选只用于一次洗牌；继续修改时重新读取装备。

标记为 **「主要／史诗」** 的槽位可以在这两类合法词条中选择，准备洗牌时会同时设置对应的生成类别，避免选择史诗后又随机生成主要。适用于符合品质条件的项链、护甲、主武器、靴子和戒指；项链、戒指本身保证生成的首条史诗仍保持史诗类别。其他槽位继续保留原来的主要、次级或史诗分类。

v2.4 按装备实际数据列出全部词条，支持 7 条及更多词条，当前游戏槽位上限为 10；不增加装备原有词条数量。列表较长时可滚动选择。

允许在同类槽位之间交换原词条；整套最终结果不能重复，与固定或锁定词条也不能冲突。选择过程中暂时重复时，请继续调整其他槽位，消除重复后才能准备整套洗牌。

**所有未锁定的普通词条都会参与本次洗牌，数值均重新随机。** 未改目标的槽位仍洗出原词条，但不会保留原数值。要连数值也保留的词条，可以在游戏中锁定后重新读取。

固定传奇能力、套装能力、符文，以及锁定的词条不能替换。词条数量、适用部位、职业／元素限制、重复检查、等级与品质对数值的影响、洗牌费用、名称和评分更新均继续走游戏原有流程；本功能不提供任意数值输入或免除费用。游戏可能按默认的史诗、主要、次级顺序排列洗出的词条。

锁定状态或目标装备变化后需重新读取。点击「取消整套预选」、关闭附魔窗口或恢复原始状态会取消尚未生效的选择；已经完成的游戏洗牌不会撤销。如果准备后换了装备，工具检测到目标变化会取消覆盖，该次游戏操作仍会按游戏原规则处理。若本次仅执行部分预选或洗牌没有生成词条，洗牌返回时会取消剩余预选，不会留到下一次洗牌；请检查游戏结果并重新读取。

本功能读取当前本机第 1 个角色的附魔师数据，仅适用于本机单人游戏。附魔师操作尚未解锁、资源不足或其他游戏条件未满足时，仍需按游戏要求处理。

已实测：100 级「王之岩」在 5 条普通附魔均未锁定时，**一次洗牌**同时得到击杀囤积（12）、移动速度（11）、攻击速度（8）、冷却时间减少（7）、寻宝值（11），用户确认全部结果。固定能力、保护槽位、锁定／符文／固定标志及基础装备数据不变，全部临时补丁恢复通过核对。其他装备和所有候选词条未逐一实测。

v2.4 已实测并由用户确认：100 级「断颈者」完整识别 7 条词条，第 7 条成功洗为寻宝值；100 级「昂首阔步」第 3 条移动速度成功转为史诗反击减速，再转回主要移动速度。两组测试的固定能力、保护槽位数值、词条标志和基础装备数据保持不变，全部临时补丁恢复后回读一致。其他部位的双向转换通过方案和界面测试，未逐一进行游戏内洗牌。



实现与验证细节见「附魔词条功能说明.md」。

## 独特敌人追踪与一键去迷雾（v2.5）

左侧选择 **「独特敌人追踪」**，勾选右侧「显示独特敌人位置」并应用。打开页面本身不会开启标记。紫色表示已生成且存活的独特敌人，橙色表示互动前的触发物；面板列出名称、世界坐标和距玩家的距离。家中的木人不参与识别。

已适配的互动前目标：沃尔坎姆的伪装石头、尼的特殊草丛、格洛德的珍稀烛台。DLC 中已经生成的独特敌人使用相同的通用识别流程；DLC 其他特殊互动或剧情触发物在激活前尚不能保证全部覆盖，且未进行 DLC 地图实测。

切换到其他功能页后，已开启的追踪继续运行；取消“显示独特敌人位置”并应用可停止标记。主窗口“恢复全部功能”或正常退出综合修改器会恢复全部运行时补丁。不要同时运行旧版独立标记程序。

追踪只在进入地图、进图初始化补查以及独特敌人生成事件时遍历地图。平时仅核对缓存目标的生命值、触发状态、坐标和玩家位置；击杀后清除标记，不重新遍历全图。地图读取不再暂停游戏，仅在安装、恢复和发布少量标记数据时短暂同步。贫瘠之地实测完整读取约 21 毫秒，稳定追踪平均约 0.03 毫秒，静止期间不再重复全图扫描；不同地图、目标数量与机器负载下耗时会变化。

左侧选择 **「地图点亮」**，点击 **「点亮当前地图一次」**，切回游戏等待地图自然刷新。该按钮点亮当前已载入地图的全部迷雾，不影响尚未载入的其他地图；探索状态会按游戏自身机制保存。“恢复原始状态”恢复运行时补丁，不撤销已经完成的地图探索。贫瘠之地已通过游戏原生探索函数执行，并经用户确认整图点亮。

v2.6 新增 **「进入新地图时自动点亮迷雾」** 开关，默认不勾选；v3.0 修改后点击「应用自动点亮开关」。开启后会先点亮当前地图一次；之后每次进入地图，等待初始化完成并由游戏自然刷新时自动执行一次。同一张地图不会反复执行，手动已提交或已完成的点亮请求也不会重复触发。该功能不依赖独特敌人追踪，关闭地图面板后仍有效；取消勾选可停止自动点亮并取消尚未开始的自动请求。主窗口恢复全部功能或退出修改器会关闭自动点亮。

地图绘制和去迷雾均跟随游戏自身的地图刷新时机；不会从 SYSTEM Step2 提前执行地图刷新脚本。切图时旧请求会核对地图和图层，避免对错误地图执行。
